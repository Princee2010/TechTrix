DocuMind AI

Version {{ version }} · Ask your documents. Find answers instantly.

Problem

Finding one fact in hundreds of PDF pages means opening files, searching keywords and reading page after page.

Objective

Answer questions from the user's own PDFs, cite the exact page, and say so plainly when the documents don't contain the answer.

How it works

  1. PyMuPDF reads each PDF page by page.
  2. Text is split into chunks that stay within a single page.
  3. Sentence Transformers turn chunks into embeddings, stored in FAISS.
  4. A question is embedded and matched against the selected documents.
  5. If no passage passes the relevance threshold, no answer is generated.
  6. Otherwise Gemini answers from those passages only, and each source links to its PDF page.

   ├─ answer_service → Gemini
   └─ SQLite (documents, chunks, chats)  +  uploads/ (original PDFs)
